# pipecodes
Four files starting with demo_lqr correspond to four numerical examples respectively: pre-buckling simply supported pipe, post-buckling simply supported pipe, fluttering cantilevered conveying pipe, and cantilevered conveying pipe with chaotic motion. Buildmodel file serves as the model file for all examples, it performs simulations and generates free vibration data and controlled response data. Files named which include LQR and DMD cover the sections of linear quadratic optimal control and dynamic mode decomposition in the examples. They are referenced separately across different cases and modified accordingly for each application. The file named LSTM contains the implementation of the long short-term memory neural network. It reads vibration data from simulations to train the control compensation terms, which are then applied for optimal control in the main program.The files already contain the LSTM training results and provide a reference program for Lyapunov exponent calculation.
